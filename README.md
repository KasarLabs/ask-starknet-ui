# Ask Starknet UI

This repository contains the frontend for Ask Starknet.

## Getting Started

```bash
pnpm install
pnpm dev
```

The app runs on http://localhost:3000 by default.

## Available Scripts

- `pnpm dev` – launch the Next.js development server.
- `pnpm build` – create a production build.
- `pnpm start` – start the production server.
- `pnpm lint` – run ESLint.
- `pnpm check-types` – run TypeScript in no-emit mode.
- `pnpm format` – check formatting with Prettier.
- `pnpm format:write` – write formatting changes.

## Environment

Copy `.env.example` to `.env.local` (or `.env`) and fill in the values you need. The `.env` file itself is ignored from version control.
