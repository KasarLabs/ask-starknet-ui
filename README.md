# Ask Starknet UI

This repository contains the frontend for Ask Starknet.

## Getting Started

```bash
bun install
bun run dev
```

The app runs on http://localhost:3000 by default.

## Available Scripts

- `bun run dev` – launch the Next.js development server.
- `bun run build` – create a production build.
- `bun run start` – start the production server.
- `bun run lint` – run ESLint.
- `bun run check-types` – run TypeScript in no-emit mode.
- `bun run format` – check formatting with Prettier.
- `bun run format:write` – write formatting changes.

## Environment

Copy `.env.example` to `.env.local` (or `.env`) and fill in the values you need. The `.env` file itself is ignored from version control.
